## One-liner

Generate a complete, print-ready codeword puzzle book interior — interlocking word grids, number keys, given letters, solutions section — where every puzzle is machine-verified before it is allowed into the book.

## The problem

Codeword books sell steadily on KDP, but making them is the bottleneck: laying out interlocking grids by hand takes hours per book, and one bad grid (a non-word run, a number that means two letters) means a 1-star review and a refund. Generic puzzle software rarely checks its own work.

## What it does

- Pick puzzle count (25–200), grid size (13×13 or 15×15), given letters (2–4) and trim size (6×9, 7×10, 8.5×11) — get one print-ready interior PDF
- Words interlock crossword-style from a built-in list of **1,325 real English words** (corpus-harvested and dictionary-verified — no made-up filler, no proper nouns)
- Every puzzle's number key is a true one-to-one mapping; the given letters are chosen from the most frequent letters so solvers can actually start
- Solutions section at the back, one per puzzle
- **Verification layer (the point):** before a puzzle enters the book, an independent checker re-scans its grid — every run of 3+ cells must be a real word, every 2-cell run a valid two-letter word, no isolated letters, the letter↔number mapping must be a bijection, the givens must match the solution, and letter cells + blocks must equal the grid size. Failures are discarded and regenerated, never shipped
- Build report lists per-puzzle word counts, letter cells and distinct letters

## Measured (seeded acceptance test, 15/15 checks passed)

- 3-puzzle 11×11 test book: all puzzles re-verified clean, cell conservation exact (e.g. 73 letters + 48 blocks = 121), 19 distinct letters per puzzle, PDF page count exact (title + 3 puzzles + divider + 3 solutions = 8)
- Same seed regenerates puzzle 1 identically — fully deterministic
- Default 15×15 puzzle: 25 words placed, 128 letter cells, 20 distinct letters, generated and verified in under a second

## Honest limits

- Numbers run 1..N for the N distinct letters in each puzzle (a single 15×15 grid rarely uses all 26 letters) — the key strip on each page shows exactly the numbers in play
- Interior only: no cover design, no ISBN — KDP cover is a separate step
- Word list is common English; themed vocabulary (medical, sports) is not included in this version
