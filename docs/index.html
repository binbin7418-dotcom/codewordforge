The verification (why this exists)

One bad grid — a non-word run, a number that means two letters — is a 1-star review. So an independent checker re-scans every candidate puzzle: every run of 3+ cells must be a real word, every 2-cell run a valid two-letter word, no isolated letters, the number key must be a bijection, the givens must match the solution, and the cells must add up. Failures are discarded and regenerated. They never ship.
